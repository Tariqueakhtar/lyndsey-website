# Lyndsey Austin Transformations — Website

Static marketing/lead-generation site for Lyndsey Austin Transformations (confidence coaching, mindset and fitness transformation, Dubai, UAE). No backend — every CTA routes to WhatsApp.

See [CLAUDE.md](CLAUDE.md) for full project context, design system, section-by-section breakdown, known placeholders, and deployment steps (Azure Static Web Apps).

## Quick start

Open the folder in VS Code and use the **Live Server** extension: right-click `index.html` → "Open with Live Server". No build step or dependencies required.
